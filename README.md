archplan-2d

Eksperimen software rasterizer 2D sederhana dan penampil denah arsitektur (floor plan) menggunakan JavaScript dan WebGL (Three.js).

Gambaran Proyek

Proyek ini bertujuan untuk mempelajari dasar-dasar rendering pipeline 2D:

Menggambar garis dan bidang poligon/segitiga secara manual langsung ke framebuffer piksel.

Menampilkan visualisasi denah bangunan 2D di web menggunakan Three.js.

Status

🚧 Dalam tahap inisialisasi awal. Struktur kode dan implementasi primitif akan ditambahkan secara bertahap.
